# Web Scraper

## Project Description

This project is a Python web scraper built using Requests and BeautifulSoup.

It extracts headlines from a public Python blog page and saves the collected headlines into a CSV file.

## Technologies Used

- Python
- Requests
- BeautifulSoup
- CSV

## Files

- scraper.py - Python web scraping program
- headlines.csv - Extracted headlines
- README.md - Project documentation

## How to Run

Install the required libraries:

pip install requests beautifulsoup4

Run the program:

python scraper.py

The extracted headlines will be saved in headlines.csv.
